Fichiers d'exigences pour essayer la vérification avant import

Prérequis : les exigences de test exigences/2026-01-01-fct1.xlsx à fct10.xlsx sont chargées dans la base (tomes fct1 à fct10, release A). Vérifier ces fichiers avec la loupe de la boîte Exigences, un par un ou ensemble ; rien n'est importé.

Chaque fichier reprend les exigences de la release A de son tome, telles que la base les contient, puis y introduit le cas décrit ; un fichier ne signale donc que son cas.

La vérification ne se sert pas du nom du fichier : chaque exigence est cherchée dans toute la base. Le rapport donne pour chaque fichier ce qui se passe s'il écrase la base (import en remplacement) et s'il la modifie (import en complément) ; les résultats ci-dessous valent pour les deux cas, sauf mention.

Régénérer : python ../../base-test/generateurs/make_verification_exigences.py ../../base-test depuis nexus-v/programme.
