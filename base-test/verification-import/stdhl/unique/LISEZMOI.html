Prérequis : les exigences, les plans et les STDHL de test fct1 à fct10 sont chargés dans la base. Vérifier ces documents avec la loupe de la boîte STDHL ; rien n'est importé. Ils sont au format unique : aucun tableau STDHL, un titre par test, sa liste « Exigences associées » et ses test cases.

La couverture d'un test est l'ensemble des exigences de ses test cases ; ses exigences associées doivent être exactement celles-là : une exigence dans une seule des deux parties refuse le fichier (Bloquant), comme une applicabilité d'une autre release que la base. Le rapport donne pour chaque fichier ce qui se passe s'il écrase la base et s'il la modifie ; les résultats ci-dessous valent pour les deux cas, sauf mention. Chaque rapport rappelle aussi les exigences de TOP déjà sans STDHL dans la base (À vérifier), non répétées ci-dessous.
