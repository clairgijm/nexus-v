STDHL « unique » de complément et de remplacement

Prérequis : les exigences, les plans et les STDHL de test fct1 à fct10 sont chargés dans la base. Chaque document couvre les 10 tomes, au format unique.

  • complement/ : 5 % des exigences demandées pour un autre test du même tome, et 2 exigences nouvelles par tome (SSS_FCTk_REQ_500, 501, celles des fichiers d'exigences de complément) sous un test SYS_NOUVEAU_FCTk_001. Dans le rapport, regarder la partie « Si le fichier modifie la base ».
  • remplacement/ : tout le contenu, moins 5 % d'exigences retirées, 5 % demandées pour un autre test, et 2 exigences nouvelles par tome (SSS_FCTk_REQ_600, 601). Dans le rapport, regarder la partie « Si le fichier écrase la base ».

Tant que les exigences nouvelles ne sont pas importées, elles sont « exigences inconnues de la base » (À régler). Les exigences retirées « perdent leur STDHL avec l'import » si le fichier écrase la base.
