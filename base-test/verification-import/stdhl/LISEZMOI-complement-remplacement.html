STDHL de complément et de remplacement

Prérequis : les exigences, les plans et les STDHL de test fct1 à fct10 sont chargés dans la base.

  • complement/ : STDHL à importer en complément : 5 % des exigences du STDHL demandées pour un autre test, et les exigences nouvelles des fichiers d'exigences de complément (SSS_FCTk_REQ_500…), sous un test SYS_NOUVEAU_FCTk_001. Dans le rapport, regarder la partie « Si le fichier modifie la base ».
  • remplacement/ : STDHL à importer en remplacement, de même nom que celui de la base : tout le STDHL, moins 5 % d'exigences retirées, 5 % demandées pour un autre test, et les exigences nouvelles des fichiers d'exigences de remplacement (SSS_FCTk_REQ_600…). Dans le rapport, regarder la partie « Si le fichier écrase la base ».

Tant que les exigences nouvelles ne sont pas importées (avec leur ligne de plan), elles sont signalées « exigences inconnues de la base » (À régler). Les exigences retirées « perdent leur STDHL avec l'import » si le fichier écrase la base.
