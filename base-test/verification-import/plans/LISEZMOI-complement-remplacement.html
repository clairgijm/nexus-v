Plans de complément et de remplacement

Prérequis : les exigences et les plans de test fct1 à fct10 sont chargés dans la base.

  • complement/ : plans à importer en complément : 5 % des lignes du plan modifiées, et des lignes pour les exigences nouvelles des fichiers d'exigences de complément (SSS_FCTk_REQ_500…). Dans le rapport, regarder la partie « Si le fichier modifie la base ».
  • remplacement/ : plans à importer en remplacement : tout le plan, moins 5 % de lignes retirées, 5 % de lignes modifiées, et des lignes pour les exigences nouvelles des fichiers d'exigences de remplacement (SSS_FCTk_REQ_600…). Dans le rapport, regarder la partie « Si le fichier écrase la base ».

Tant que les fichiers d'exigences correspondants ne sont pas importés, les exigences nouvelles sont signalées « exigence inconnue de la base » (À régler) ; une fois importées, elles apparaissent comme « sans ligne de plan dans la base, couvertes par ce plan ».

Une ligne modifiée change un champ, à tour de rôle, dans le respect des règles IADT / MOC : l'IADT (D et T échangés, MOC4 gardé), le MOC (MOC2 et MOC3 échangés, IADT A) ou la délégation (TOP devient PLT2_N-1, une plateforme devient TOP). Les lignes retirées laissent leurs exigences sans ligne de plan si le fichier écrase la base.

Régénérer : python ../../base-test/generateurs/make_verification_plans.py ../../base-test depuis nexus-v/programme.
