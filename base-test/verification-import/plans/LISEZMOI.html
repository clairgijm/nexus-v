Plans pour essayer la vérification avant import

Prérequis : les exigences et les plans de test (exigences/2026-01-01-fctk.xlsx, plans/2026-01-01_PA_FCTk_A-plan.docx) sont chargés dans la base, ainsi que les plateformes PLT1_N-1 à PLT14_N-1. Vérifier ces fichiers avec la loupe de la boîte Plan d'acceptation ; rien n'est importé.

La vérification ne se sert pas du nom du fichier : chaque exigence est cherchée dans toute la base, et sa ligne comparée à celle des plans de la base. Le rapport donne pour chaque fichier ce qui se passe s'il écrase la base (les plans des tomes concernés sont remplacés) et s'il la modifie (ses lignes remplacent celles des mêmes exigences) ; les résultats ci-dessous valent pour les deux cas, sauf mention.

Régénérer : python ../../base-test/generateurs/make_verification_plans.py ../../base-test depuis nexus-v/programme.
